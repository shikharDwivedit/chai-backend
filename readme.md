# 🎬 Movie Recommendation Platform

> A full-stack movie recommendation platform focused on helping users discover movies through personalized suggestions, search, and user-based interactions.

---

# 📌 Overview

This project is a movie recommendation platform designed to provide users with a better movie discovery experience.

The platform currently focuses on:
- Movie browsing
- Recommendation features
- Search functionality
- Authentication
- Watchlists and favorites
- Scalable backend architecture

---

# 🚀 Current Features

## 👤 Authentication System

- User Signup/Login
- JWT Authentication
- Protected Routes

---

## 🎥 Movie Browsing

- Browse movies dynamically
- View posters, ratings, genres, and release details
- Trending and popular movie sections

---

## 🔍 Search Functionality

- Search movies instantly
- Fast retrieval of movie data

---

## ⭐ Recommendation System

- Genre-based recommendations
- Similar movie suggestions
- Personalized recommendation logic

---

## 📂 Watchlist & Favorites

- Save movies for later
- Manage favorite movies

---

## ☁️ Backend Infrastructure

- REST API architecture
- MongoDB integration
- Express.js backend
- Organized MVC structure

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/your-repo-name.git
```

---

## Install Dependencies

### Backend

```bash
cd backend
npm install
```

### Frontend

```bash
cd frontend
npm install
```

---

# ▶️ Run Project

## Start Backend

```bash
npm run dev
```

## Start Frontend

```bash
npm start
```

---

# 🔐 Environment Variables

Create a `.env` file:

```env
PORT=5000

MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_secret
```
